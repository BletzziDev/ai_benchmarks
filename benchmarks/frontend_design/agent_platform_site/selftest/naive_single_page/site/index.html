Frequently asked questions

How long does a typical deployment take?

Most customers run their first agent in production within four to six weeks, including validation on historical data.

Can agents take actions without approval?

Only within the limits you define. Anything above a threshold, outside a policy or flagged as unusual is routed to a human.

Where is our data stored?

In your chosen region (EU or US). Enterprise customers can run Orbital in a dedicated environment with customer-managed keys.

Which models do you use?

Orbital is model-agnostic. We evaluate leading models for each workflow and you can pin or restrict the models an agent may use.

What happens if an agent makes a mistake?

Every action is logged and reversible where the target system allows it. Agents escalate when confidence is low, and you can pause any agent instantly.
