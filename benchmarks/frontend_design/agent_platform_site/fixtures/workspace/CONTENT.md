## Features (section heading: "Everything you need to run agents in production")
1. Guardrails by default — Every agent runs with scoped permissions, spending limits and a policy engine that blocks risky actions before they happen.
2. Human-in-the-loop approvals — Route high-impact steps to the right person in Slack or email, with full context and one-click approve or reject.
3. Complete audit trail — Every observation, decision and tool call is recorded and searchable, so compliance reviews take minutes, not weeks.
4. Connects to your stack — Native connectors for Salesforce, ServiceNow, SAP, Snowflake and 180+ systems, plus a typed SDK for everything else.
5. Evaluated before production — Replay real historical cases against new agent versions and ship only when quality and safety scores improve.
6. Enterprise-grade security — SOC 2 Type II, ISO 27001, SSO/SAML, customer-managed keys and regional data residency in the EU and US.

## How it works (section heading: "From first connection to full autonomy in four steps")
1. Connect — Link your systems with read-only access first. Orbital maps your data and processes in a sandbox.
2. Design — Describe the workflow in plain language. Orbital proposes an agent, its tools and its guardrails for your review.
3. Validate — Run the agent against thousands of past cases. Review its decisions and approve the rollout plan.
4. Operate — Go live with gradual autonomy. Dashboards show throughput, quality and every escalation in real time.

## FAQ (section heading: "Frequently asked questions")
1. How long does a typical deployment take? — Most customers run their first agent in production within four to six weeks, including validation on historical data.
2. Can agents take actions without approval? — Only within the limits you define. Anything above a threshold, outside a policy or flagged as unusual is routed to a human.
3. Where is our data stored? — In your chosen region (EU or US). Enterprise customers can run Orbital in a dedicated environment with customer-managed keys.
4. Which models do you use? — Orbital is model-agnostic. We evaluate leading models for each workflow and you can pin or restrict the models an agent may use.
5. What happens if an agent makes a mistake? — Every action is logged and reversible where the target system allows it. Agents escalate when confidence is low, and you can pause any agent instantly.
